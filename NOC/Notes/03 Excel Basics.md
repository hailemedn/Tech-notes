# Excel Basics

## Shortcuts
- Format cells -> ctrl +1

#### Autofit to context
- Double click the line at the end of the column
- select everything and double click any line in between columns

#### Unhide column
- select the start and the end columns of the hidden, then right click - unhide

#### Move column
- select the column
- press shift and select the start of the column and drag
